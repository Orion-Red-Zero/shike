# 食刻 1.3.0 版本说明

发布包：`app.shike.diet.fixed` · `versionCode 5` · `versionName 1.3.0`  
基线：食刻 1.2.0 源码包，原 SHA-256 `966d4927c55fd8bae612ad59b65c6a62d56296bf15bab695de769a1d18642822`。

## 新增与改进

1. 增加减脂 / 维持 / 增肌目标、身体参数、活动水平、自动热量估算与手动目标。
2. 增加训练日 / 休息日蛋白质、碳水、脂肪目标及首页进度环。
3. 增加力量 / 有氧训练、编辑删除、动作容量、MET 消耗估算和训练模板。
4. 增加体重、腰围、体脂率、同日更新、身体趋势和 7 日移动平均。
5. 增加每周总结及饮食 / 训练 / 身体趋势切换。
6. 完整 JSON 覆盖新旧数据；新增训练和身体 CSV；支持经确认导入 1.2.0 JSON。
7. 修正普通浏览器被误判为 Android 的问题：只有检测到原生桥时才走 Android 分支，PWA 可注册 `shike-v1.3.0` 并离线重载。
8. 修复窄屏顶栏折行：390 px 使用短“安装”标签，320 px 隐藏该入口；布局测试同时检查副标题不折行和主按钮触控尺寸。

## 数据兼容

- 继续使用 `shike-food-energy-ledger-v1`，不删除旧饮食、食物库或原设置。
- 旧数据在内存中迁移到 schema 2，首次保存后持久化新增字段。
- 坏 JSON、结构不合法或更高版本备份不会替换现有数据。
- 完整迁移请使用 JSON；CSV 不能恢复目标、模板或全部关联数据。

## 签名与安装限制

本次 APK 使用新本地证书，**不能覆盖安装旧签名 1.2.0**。旧 APK 的证书 SHA-256 为：

`df2e3ce99ba4cd1ea31ec94adecb4e1877c7cc9ad8159ff33733a39535bd75b3`

旧签名私钥未包含在可恢复材料中。迁移前必须从旧版导出 JSON；卸载旧版会清除未备份的应用私有数据。安装新版后再导入并核对。新证书指纹以本次 `Shike_1.3.0_verification.json` 为准。
