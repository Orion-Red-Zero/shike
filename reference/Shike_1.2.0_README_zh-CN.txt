系统要求：Android 10 及以上（API 29）

本版变化
--------
1. 自定义食物升级为全局“我的食物库”：可在“记一笔”或“我的”进入，一次保存后跨早餐、午餐、晚餐、加餐和不同日期直接复用。
2. 支持食物名称、别名、每 100 g 营养数据和常用份量；提供搜索、编辑、删除及“记一笔”。编辑只影响后续记录，删除不改写历史记录快照。
3. 拍照前先在本机缩放并转为 JPEG，最长边 1600 px，减少上传大小；原图不会因识别失败被转换为本机饮食记录。
4. 可配置兼容的照片识别服务，展示食物种类置信度、重量估算置信度、重量范围及参考物；支持逐项或全部加入待确认，并防止重复加入。
5. 识别候选可手动选择食物或搜索 USDA 匹配。热量始终按最终所选食物的营养数据与用户确认克数在本地重算，不采用服务自报热量。
6. 保留文字记录、四餐汇总、趋势、CSV/JSON 导出、本机数据键和可见启动诊断；修复内置米饭“一碗”被静默改成 USDA 一杯的问题，仍明确按应用假设 1 碗 = 150 g。

重要精度边界
------------
- 单目照片无法可靠还原食物的绝对克重，也不能保证种类识别准确率。重量范围、参考物与两类置信度用于帮助核对，不等于称重测量。
- 所有照片候选必须先核对食物与克数，再确认计入；缺少有效克数、清空或填入负数时不会按默认 100 g 入账。
- 未配置识别服务或未授权上传时，应用不会上传照片，也不会生成虚假食物或热量，可改用手动标注。
- 本版的识别请求与 USDA 在线响应测试使用明确标注的协议夹具，不代表真实食物照片的识别准确率或实时查询结果。

安装与升级
----------
- 若手机提示，请仅对本次使用的文件管理器或浏览器允许“安装未知应用”。
- 已安装食刻修复版 1.0.1 或食刻 1.1.0：本版包名与签名证书相同，可尝试直接覆盖安装；不要先卸载。正常情况下本机记录会保留，但升级前请先在“我的 → 数据”导出 JSON/CSV 备份。
- 最早 1.0.0 使用不同包名，数据不会自动迁移；请先从原应用导出备份。
- 若系统提示签名冲突，不要直接卸载以覆盖：卸载会清除该应用的本机记录。请先备份并核对当前安装包来源。
- 本包为本地构建签名，不是应用商店发布签名。

使用与数据
----------
- 文字记录、内置食物、全局食物库、汇总、趋势与导出可离线使用。
- USDA 在线搜索和自行配置的 HTTPS 照片识别服务需要网络；DEMO_KEY 可能有限额，正式使用建议申请自己的 USDA API Key。
- 记录保存在应用本机存储中。清除应用数据或卸载会删除记录，请定期导出备份。
- 导出文件保存在系统“下载/食刻”目录（由系统存储能力支持时）。
- 热量为饮食记录估算，不用于医疗诊断或处方。
